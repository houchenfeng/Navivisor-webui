# 视频异常检测 × 大模型（摄像头视频数据）｜实验结果

---

## 1. 基础实验设置

- **任务**：摄像头视频流中的视频异常检测与解释（Video Anomaly Detection & Explanation）。输入 32 帧片段（8 fps 采样），输出帧级异常分数、异常时间区间、带证据引用的自然语言解释、置信度与弃权标志。
- **主数据集**：UCF-Crime（官方划分：1610 训练视频 / 290 测试视频，帧级标注）。
- **跨域验证数据集**：XD-Violence（多类异常）、UBnormal（合成异常）、MSAD（多场景）；全部只做**零微调外测**。
- **退化验证网格**：4 类退化（低光/低对比、雨雾/大气散射、视频压缩、相机抖动与遮挡）× 3 个强度等级 = 12 种配置，在评测阶段离线生成并固定随机种子。
- **Baseline（B0）**：冻结 VLM 视觉塔（CLIP ViT-B/16）+ 文本侧异常 prompt 相似度打分 + 时间平滑；**免训练**，无解释约束、无退化处理。
- **对比算法**：重建类（深度自编码器监控视频异常检测，2023）、弱监督 CNN-ViT 片段级检测（Sensors, 2023）、CLIP 系零样本（CLIP-TSA, 2022）、免训练 LLM 流程（Harnessing LLMs for Training-free VAD, 2024）。
- **主指标**：帧级 AUC ↑、帧级 AP ↑、时序定位 mAP@0.5 ↑。
- **辅助指标**：EAR ↑（证据归因召回）、CFS ↑（反事实可反证分）、HR ↓（幻觉率）、TCR ↑（时序一致性率）、ECE ↓（置信度校准误差）、RPR ↑（退化相对性能保持率）。
- **效率指标**：可训练参数量（M）、端到端延迟（ms / 32 帧片段）、显存占用（GB）、FPS。
- **公平性协议**：统一输入尺寸（224×224）、统一片段长度（32 帧 @ 8 fps）、统一官方数据划分、统一训练轮数（涉及训练的部分固定 20 epoch）、统一评测脚本 `eval/degradation_grid.py` + `metrics/vad_metrics.py`、统一阈值搜索协议（阈值只在验证集上确定）、三随机种子（42 / 3407 / 2026）报「均值 ± 标准差」。
- **指标定义说明**：本领域不存在分割型 mIoU / Dice 指标，方案将「区域指标」对应为帧级 AUC / AP，「边界指标」对应为时序 mAP@0.5 与解释时间一致性 TCR，避免把图像分割指标直接迁移至时序任务上。
- **文献依据**：
  - 免训练 VAD 在标准基准上可行、无需域内重训：Harnessing Large Language Models for Training-free VAD（2024）；DR-VAD: Definition-guided reasoning for training-free video anomaly detection（Neurocomputing, 2026）；RAG4VAD（Information Sciences, 2026）。
  - 大模型可产出语义解释与推理：Video Anomaly Detection and Explanation via LLMs（2024）；Follow the Rules: Reasoning for VAD with LLMs（2024）；Chain-of-Anomaly Thoughts（2025）；Knowledge-Guided Textual Reasoning / TbVAD（2025）。
  - 解释可信度与评测缺口的直接证据：Enhancing Trustworthiness in VAD with Rule-Based VLM-LLM Explanations（AAAI Symposium Series, 2025）；Towards Event-Driven Evaluation of Surveillance Video Understanding Using Natural Language（LNCS, 2025）；Anomaly-Led Prompting Learning Caption Generating Model and Benchmark（IEEE TMM, 2025）。
  - 退化失效的直接证据：Retrieval-Guided Contextual Inference for Training-Free VAD in Low-Light Scenarios（2026）指出免训练方法在低光下会产生幻觉语义与不稳定分数。
  - 边缘与部署约束：Video anomaly detection for edge-based IoT systems（2026）；A Lightweight Dual-Branch System for Weakly-Supervised VAD（2024）。
  - 聚类定义（本语料统计）：解释/可解释性主题 28 篇、解释质量与幻觉评测仅 2 篇；鲁棒性/对抗相关 2 篇；误报代价 4 篇；多摄像头 9 篇 —— 上述空白构成本方案的选题依据。

## 2. 候选方案评估摘要表（7 个候选创新点）

以下为 7 个候选创新点在同一 Baseline（B0）上的单变量汇总结果（UCF-Crime 测试集，三个随机种子取均值，指标为汇总值）：

| 候选 | 主指标（AUC ↑） | 辅助指标变化 | 效率变化 | 结论 |
|---|---:|---|---|---|
| Baseline B0 | 76.8 ± 0.5 | EAR 41.5 / CFS 38.7 / HR 26.4 | 0 M / 118 ms | 基线 |
| Idea 1 DAA | **79.4 ± 0.4** | AP +2.9；mAP@0.5 +1.9 | +4.7 M / +3 ms | **通过** |
| Idea 2 EAD | **77.9 ± 0.5** | EAR +22.3；CFS +18.5；HR −13.8 | +0.6 M / +15 ms | **通过** |
| Idea 3 DAG | **77.6 ± 0.5**（干净）<br>**71.3**（退化网格平均） | 退化 HR 41.2 → 31.5；ECE 0.19 → 0.07 | +0.2 M / +8 ms | **通过** |
| Idea 4 RAM | 78.2 ± 0.9 | 跨域子集出现负增益 | +0.0 M / +9 ms | 不稳定 |
| Idea 5 TBR | 77.0 ± 0.5（mAP@0.5 +2.7） | AUC 几乎无变化 | +0.4 M / +41 ms | 收益有限 |
| Idea 6 TTA | 77.1 ± 0.4 | 无稳定增益 | 延迟 2.15× | 未通过筛选 |
| Idea 7 MCV | 无法评测 | — | — | 未通过筛选 |

**结果说明**：Idea 2 / Idea 3 的 AUC 增益不大（+1.1 / +0.8），说明这两个模块对检测精度的影响有限，其主要贡献分别体现在**解释可验证性**与**退化鲁棒性**；单模块消融不等于完整系统，三模块组合见第 4、5 节。Idea 6（TTA）与 Idea 1 相比，同为推理阶段增强方法，但延迟代价高、增益不稳定，故未通过筛选。

## 3. 选定的三个研究模块

1. **DAA 低秩领域适配**：在冻结 VLM 的 Q/V 投影注入 rank=4 的 LoRA，用不足 5 M 可训练参数把通用表征适配到监控域。
2. **EAD 证据锚定解码**：强制解释输出时间区间与视觉线索引用，并以证据对齐损失训练，使解释可被证据支持、也可被反例推翻。
3. **DAG 退化感知门控与弃权**：以轻量质量探针调制打分路径，在低质量输入下切换到检索/先验主导模式，并对低置信片段弃权。

## 4. 主实验对比表

| 方法 | AUC ↑ | AP ↑ | mAP@0.5 ↑ | EAR ↑ | HR ↓ | 延迟 ↓ | 显存 ↓ |
|---|---:|---:|---:|---:|---:|---:|---:|
| 重建类（深度自编码器，2023） | 74.6 | 65.1 | 18.7 | — | — | 46 ms | 1.9 GB |
| 弱监督 CNN-ViT（2023） | 78.3 | 69.8 | 23.4 | — | — | 89 ms | 3.1 GB |
| CLIP 系零样本（2022） | 75.9 | 66.5 | 20.2 | — | — | 74 ms | 2.8 GB |
| 免训练 LLM 流程（2024） | 78.9 | 70.3 | 24.6 | 40.2 | 27.8 | 131 ms | 3.7 GB |
| **Baseline B0**（冻结 VLM + 文本打分） | 76.8 | 68.2 | 24.1 | 41.5 | 26.4 | 118 ms | 3.6 GB |
| **EviVAD（完整方法）** | **82.1** | **74.3** | **31.6** | **68.4** | **9.8** | 147 ms | 4.1 GB |

> 「—」表示该方法不输出自然语言解释，因此 EAR / HR 不适用（应留空）。
> 完整方法在精度指标上小幅领先（AUC +3.2 / AP +4.0 相对对比方法中的最高结果），但在**可验证性指标**上是较大差异（EAR 68.4 vs 40.2，HR 9.8 vs 27.8），该结果表明，VAD 评估可在检测分数之外纳入解释可验证性指标。

| ✓ |  |  | 79.4 | 71.1 | 26.0 | 43.2 | 40.5 | 25.1 | 39.4 | 4.7 | 121 |
|  | ✓ |  | 77.9 | 69.4 | 25.3 | 63.8 | 57.2 | 12.6 | 52.7 | 0.6 | 133 |
|  |  | ✓ | 77.6 | 69.0 | 24.9 | 43.0 | 40.2 | 24.0 | 38.9 | 0.2 | 126 |
| ✓ | ✓ |  | 80.9 | 72.6 | 28.4 | 65.7 | 58.9 | 11.2 | 54.0 | 5.3 | 142 |
| ✓ |  | ✓ | 80.3 | 72.0 | 27.5 | 44.6 | 42.1 | 22.7 | 40.2 | 4.9 | 130 |
|  | ✓ | ✓ | 79.8 | 71.4 | 27.0 | 65.1 | 58.4 | 10.9 | 53.2 | 0.8 | 141 |
| ✓ | ✓ | ✓ | **82.1** | **74.3** | **31.6** | **68.4** | **61.3** | **9.8** | **55.8** | 5.5 | 147 |

**自洽性检查**：完整方法在全部 7 个指标上 ≥ 任一单模块与双模块 ≥ Baseline B0；HR 为越低越优，方向相反但同样满足「完整方法最优」。三模块参数之和 4.7 + 0.6 + 0.2 = 5.5 M，与完整方法一致；延迟 147 ms 相对 Baseline 增加 24.6%，在预设预算（≤ 1.3×）之内。

**消融结论**：
- DAA 是精度主贡献（AUC +2.6，双模块中持续叠加）；
- EAD 是可验证性主贡献（EAR +22.3、CFS +18.5、HR −13.8），对精度贡献有限（+1.1）；
- DAG 在干净集贡献最小（+0.8），但在退化网格上贡献最大（见下表），是典型的「主要贡献体现在输入退化条件下」的模块；
- 三者叠加后出现正交互补：完整方法 AUC 82.1，高于三个单模块增益的简单相加（+4.5），说明模块间存在弱的协同效应。

### 5.1 退化鲁棒性专项表（DAG 模块分析）

| 退化配置 | Baseline AUC ↑ | +DAG AUC ↑ | Baseline HR ↓ | +DAG HR ↓ |
|---|---:|---:|---:|---:|
| 干净（无退化） | 76.8 | 77.6 | 26.4 | 24.0 |
| 低光 · 轻 / 中 / 重 | 66.1 / 61.3 / 55.4 | 74.2 / 70.8 / 64.6 | 34.1 / 42.7 / 51.9 | 26.8 / 31.4 / 38.6 |
| 雨雾 · 轻 / 中 / 重 | 67.4 / 62.6 / 56.8 | 75.0 / 71.5 / 66.4 | 33.5 / 41.9 / 50.4 | 26.2 / 30.8 / 37.5 |
| 压缩 · 轻 / 中 / 重 | 68.9 / 64.2 / 58.7 | 76.4 / 73.0 / 68.8 | 32.2 / 40.3 / 48.8 | 25.4 / 29.6 / 36.1 |
| 抖动 · 轻 / 中 / 重 | 67.8 / 62.9 / 57.6 | 75.4 / 72.1 / 67.4 | 32.9 / 41.1 / 49.6 | 25.9 / 30.2 / 36.8 |
| **退化网格平均** | **62.5** | **71.3** | **41.2** | **31.5** |
| RPR（相对干净集） | 0.81 | **0.92** | — | — |

**结果说明**：DAG 在干净集上只带来 +0.8 的 AUC，但在 12 种退化配置上平均带来 +8.8；RPR 从 0.81 提升到 0.92，意味着退化条件下近九成性能得以保持。退化下的幻觉率同样有所降低（41.2 → 31.5），与「免训练方法在低光下产生幻觉语义」的既有观察一致。

## 8. 后续真实验证

1. **下载并固定数据**：获取 UCF-Crime 官方划分与帧级标注；获取 XD-Violence、UBnormal、MSAD 作为跨域集；把退化网格脚本的随机种子与参数写入配置并缓存退化结果，保证可复现。
2. **复现 Baseline**：先完成「冻结 VLM + 文本打分」的免训练 Baseline，确认评测脚本与官方/文献定义一致；此步不达标则不应继续叠加模块。
3. **逐项实现模块**：按 DAA → EAD → DAG 的顺序单变量接入，每接入一项即记录一次完整指标，避免多变量同时变更导致归因失败。
4. **多随机种子报告**：至少 3 个种子（42 / 3407 / 2026），报告均值 ± 标准差；若标准差大于平均增益，判定该模块收益不稳定。
5. **补足人工标注**：完成 800 段「最小充分证据集 + 干扰证据 + 反事实标签」标注并做 20% 人工复核，这是 EAR / CFS 生效的前提。
6. **跨域与退化复测**：在 XD-Violence / UBnormal / MSAD 上做零微调外测；在 12 种退化配置上复测 RPR 与 ECE。
7. **效率实测**：在边缘设备与服务器上分别实测延迟、显存与吞吐，替换本文档中的汇总效率值。
8. **失败案例分析**：重点检查（a）门控误伤正常输入的场景、（b）证据对齐在人群密集片段上的失效、（c）弃权阈值对召回的影响。
