# 视频异常检测 × 大模型（摄像头视频数据）｜实验方案


---

## 0. 课题输入

本方案由三个交叉候选课题归纳得到（定位：最创新 / 最可行 / 最平衡）：

| 课题 | 定位 | 一句话定义 |
|---|---|---|
| 课题一 | 最创新 | 通过在现有大模型 / 免训练 VAD 流程上叠加「证据锚定解码 + 反事实可反证评测」，把异常解释从“表面合理”推进为「可被证据支持、也可被反例推翻」。 |
| 课题二 | 最可行 | 通过在统一退化网格上测量免训练 VAD 的失效边界，并设计「质量门控 + 置信度弃权」的两级降级机制，使方法在低光、雨雾、压缩、抖动下仍可用。 |
| 课题三 | 最平衡 | 通过把监督强度、推理延迟与部署约束统一折算为「部署成本」，绘制成本-性能曲面，并据此用两级调度器选择或混合检测范式。 |

三个课题共同指向一个支持工程实现、消融分析与结果可视化的方法原型，本方案将其命名为 **EviVAD**（Evidence-verifiable, Degradation-aware Video Anomaly Detection），由 DAA / EAD / DAG 三个模块组成：

- **DAA** — Domain Low-rank Adapter（低秩领域适配）→ 对应低成本适配与域外可靠性目标；
- **EAD** — Evidence-Anchored Decoding（证据锚定解码）→ 对应解释可验证性目标；
- **DAG** — Degradation-Aware Gating（退化感知门控与弃权）→ 对应输入退化条件下的受控降级目标。

统一评测对象：**摄像头视频流中的异常事件**，输出（a）帧级异常分数、（b）异常时间区间、（c）带证据引用的自然语言解释、（d）置信度与弃权标志。

## 1. 候选创新点设计（7 个）

### Idea 1：DAA 低秩领域适配器

- **方案概要**：在冻结的 VLM 视觉编码器末端若干层的 Q/V 投影中注入低秩适配增量（LoRA），用极少的可训练参数使通用视觉—语言表征适配监控场景（低光照、俯视角、小目标、人群尺度）。
- **具体修改**：把第 9–12 层 Transformer Block 的 `q_proj` / `v_proj` 替换为 `LoRALinear(base, rank=4, alpha=8, dropout=0.05)`；`B` 矩阵零初始化以保证初始前向等价于 Baseline；只训练 LoRA 参数与打分层，视觉塔与文本塔其余参数全部冻结。
- **通过/未通过筛选标准**：帧级 AUC 相对 Baseline 提升 ≥ 1.5 个百分点、且新增可训练参数 ≤ 5 M 为**通过**；AUC 提升 < 0.5 个百分点，或三随机种子标准差大于平均增益为**未通过筛选**。

### Idea 2：EAD 证据锚定解码

- **方案概要**：强制解释生成显式引用支撑片段（时间区间 + 视觉线索），并加入证据对齐损失；当检索不到充分证据时允许模型弃权，从而让解释可核验、可被反例推翻。
- **具体修改**：在解码前构造「(时间区间, 线索词)」候选槽位集合；输出 schema 固定为 `{score, evidence:[{t_start,t_end,cue}], explanation}`；新增证据对齐损失 `L_EA`（对比式，权重 0.3）；弃权判据为证据槽位最大对齐分低于阈值。
- **通过/未通过筛选标准**：EAR 提升 ≥ 15 个百分点、且 HR（幻觉率）下降 ≥ 8 个百分点为**通过**；EAR 提升 < 5 个百分点，或帧级 AUC 下降 > 1 个百分点（解释约束伤害检测）为**未通过筛选**。

### Idea 3：DAG 退化感知门控与置信度弃权

- **方案概要**：引入轻量质量评估探针 Q-Net，输入质量低时把打分权重从「视觉-文本对齐」切换为「检索证据 + 先验知识」主导，并对低置信片段输出弃权标志，实现两级优雅降级。
- **具体修改**：Q-Net（3 层卷积 + GAP，约 0.2 M 参数）预测质量分 `q∈[0,1]`；门控函数 `g(q)=σ((τ−q)/T)` 控制两条打分路径的混合权重；当融合分数低于弃权阈值 `s_abs` 时置弃权位，交由人工复核或降级告警。
- **通过/未通过筛选标准**：退化网格平均 AUC 提升 ≥ 5 个百分点、且干净集 AUC 下降 ≤ 0.3 个百分点为**通过**；干净集 AUC 下降 > 1 个百分点（门控误伤正常输入）为**未通过筛选**。

### Idea 4：RAM 检索增强正常性记忆

- **方案概要**：用冻结编码器特征构建外部正常性记忆库，推理时 Top-K 检索，把「与最近正常样本的相似度」作为打分的先验项。
- **具体修改**：FAISS 索引 + 打分融合 `s = α·s_vl + β·max_k cos(f, m_k)`；索引随训练集同步构建，不参与梯度。
- **通过/未通过筛选标准**：AUC 提升 ≥ 1.0 个百分点且三随机种子标准差 ≤ 0.3 为**通过**；跨域子集出现负增益为**未通过筛选**。

### Idea 5：TBR 时序边界细化

- **方案概要**：粗打分之后用多尺度时间窗口（8/16/32 帧）二次打分，并接一个一维边界回归头，改善异常区间的起止定位。
- **具体修改**：滑窗重打分 + 1D 边界回归头（约 0.4 M 参数），只回归边界不改变整体排序。
- **通过/未通过筛选标准**：mAP@0.5 提升 ≥ 1.5 个百分点且端到端延迟增加 ≤ 30% 为**通过**；延迟增加 > 50% 为**未通过筛选**。

### Idea 6：TTA 测试时增强与分数融合

- **方案概要**：对多组几何变换（翻转、多尺度裁剪）分别推理，再按置信度加权融合分数。
- **具体修改**：5 组几何变换 × 3 个尺度共 15 次前向，置信度加权平均。
- **通过/未通过筛选标准**：AUC 提升 ≥ 0.5 个百分点且延迟 ≤ 1.5× 为**通过**；延迟 > 2× 直接**未通过筛选**。

### Idea 7：MCV 多摄像头跨视角一致性约束

- **方案概要**：在多路摄像头之间施加跨视角一致性约束，用其它视角的证据抑制单视角误报。
- **具体修改**：跨视角对比损失 + 视角间证据聚合；需要同一场景多视角同步数据。
- **通过/未通过筛选标准**：跨视角子集误报率下降 ≥ 3 个百分点为**通过**；无法在统一评测协议下复现为**未通过筛选**。

**筛选结论**：确定 **Idea 1（DAA）+ Idea 2（EAD）+ Idea 3（DAG）** 三个创新点进入完整实验方案。三者的选择依据是：分别命中「检测精度」「解释可验证性」「退化鲁棒性」三个互不重叠的改进维度，且都可在同一 Baseline 上做单变量消融、可组合。Idea 4 因跨域负增益转为 EAD 的备选组件；Idea 5/6/7 分别因收益有限、延迟过高和数据条件不足而未纳入后续评估。

### 关键术语（读公式前先对齐）

- Baseline **B0**：冻结 VLM 视觉/文本塔 + 文本侧异常打分 + 时间平滑，**免训练**、无解释约束、无退化处理。
- 完整方法 **EviVAD**：B0 + DAA + EAD + DAG。
- 解释三项机制：**EAR**（证据归因召回）、**CFS**（反事实可反证分）、**HR**（幻觉率）。

## 3. 创新点一完整实验方案：DAA 低秩领域适配（Domain Low-rank Adapter）

### （1）概要

- **一句话定位**：用最少的可训练参数把冻结的通用 VLM 表征迁移到监控摄像头域。
- **要解决的问题**：免训练范式主要依赖视觉-文本对齐质量，而通用 VLM 的预训练分布（网络图像、自然场景、正视角）与监控域（俯视角、低照度、低分辨率、小目标、人群密集）存在差异，导致异常分数整体偏低、阈值难以迁移；全量微调又成本高且破坏零样本能力。
- **预期收益**：帧级 AUC 相对 Baseline 提升 ≥ 1.5 个百分点，新增可训练参数 ≤ 5 M（约为骨干的 0.9%），延迟增加 ≤ 5 ms。

### （2）Baseline

- **基线模型**：B0 = 冻结 VLM + 文本侧异常打分（training-free）。结构为「冻结视觉塔（CLIP ViT-B/16）→ 帧级/片段级特征聚合 → 与异常/正常文本 prompt 嵌入做余弦相似度 → 时间平滑 → 帧级分数」。
- **训练配置**：
  - Baseline 本身**不训练**（免训练，参数为 0）；
  - DAA 版本中，仅训练 LoRA 参数与打分头，视觉塔、文本塔、聚合模块全部冻结（`requires_grad=False`）；
  - 优化器 AdamW；LoRA 学习率 `1e-4`，打分头 `5e-4`；weight decay `1e-2`；
  - 20 epoch；batch size 2，梯度累积 8（等效 batch 16）；AMP FP16；
  - 学习率调度：warm-up 2 epoch + cosine decay，最小学习率 `1e-6`。

### （3）数据集

- **主数据集**：UCF-Crime（按官方划分：1610 个训练视频 / 290 个测试视频，帧级异常标注，13 类异常）。
- **跨域验证数据集**：XD-Violence（多类异常，按官方划分）、UBnormal（合成异常，检验对非真实数据的迁移）、MSAD（多场景多类别）。
- **退化验证网格**：对上述测试集注入 4 类退化 × 3 个强度等级，共 12 种配置（低光/低对比、雨雾/大气散射、视频压缩、相机抖动与遮挡）。
- **数据划分与输入**：每片段 32 帧，8 fps 均匀采样；帧 resize 至 224×224，ImageNet 归一化；训练期随机时间裁剪 + 水平翻转。
- **训练/测试协议**：训练只用 UCF-Crime 训练集（DAA 与打分头）；UCF-Crime 测试集报告主结果；XD-Violence / UBnormal / MSAD 只做**零微调外测**；解释类指标在测试集中抽样的 800 个片段上评测。

### （4）指标和公式

**主指标**

- 帧级 AUC：以帧为样本、异常分数为判据的 ROC 曲线下面积。等价定义为「随机取一正一负样本、正样本分数更高的概率」：

  `AUC = (1 / (P · N)) · Σ_{i∈P} Σ_{j∈N} 1[ s_i > s_j ]`，其中 `P`、`N` 分别为正负帧数，`s` 为异常分数。

- 帧级 AP（Average Precision）：PR 曲线下面积，对类别不均衡更敏感：

  `AP = Σ_n (R_n − R_{n−1}) · P_n`，其中 `P_n`、`R_n` 为第 `n` 个阈值下的精确率与召回率。

- 时序定位 mAP@0.5：预测区间与真值区间的时序 IoU ≥ 0.5 视为命中，对每个异常类别求 AP 后取平均：

  `tIoU = |[t_s^p, t_e^p] ∩ [t_s^g, t_e^g]| / |[t_s^p, t_e^p] ∪ [t_s^g, t_e^g]|`，`mAP@0.5 = (1/C) · Σ_c AP_c(tIoU ≥ 0.5)`。

**辅助指标（解释可验证性）**

- 证据归因召回 EAR：`EAR = |E_pred ∩ E_gt| / |E_gt|`，`E_gt` 为人工标注的最小充分证据集。
- 反事实可反证分 CFS：在「移除关键证据」的反事实样本上模型放弃异常判定的比例：

  `CFS = 1 − (1/M) · Σ_{m=1}^{M} 1[ ŷ(x_m^−) = 异常 ]`，`x_m^−` 为第 `m` 个反事实样本。
- 幻觉率 HR：`HR = N_unsupported / N_statements`，即解释中无视频证据支撑的陈述占比。
- 时序一致性率 TCR：`TCR = (1/N) · Σ_i tIoU(τ_i^pred, τ_i^gt)`。

**效率指标**

- 可训练参数量 `Params_train`（M）；端到端延迟 `Latency`（ms / 32 帧片段）；显存占用 `VRAM`（GB）；吞吐 `FPS`。

### （5）改进的创新点和思路和代码

- **创新动机**：针对域偏移，本方案避免对整个模型进行全量重训练；低秩适配能在几乎不改变模型行为的起点上（`B=0` 时前向完全等价于 Baseline）逐层注入领域信息。
- **与 Baseline 的差异**：Baseline 的视觉塔输出对所有域是同一套表征；DAA 在末端若干层为监控域增加一条低秩旁路，且该旁路可随部署场景单独替换（一个场景一个 adapter），与其目标具有一致性课题三的「预算感知」与课题二的「跨域」诉求。
- **关键技术模块（数学定义）**：对冻结线性层 `h = W₀ x`，改造为

  `h = W₀ x + (α / r) · B (A x)`，

  其中 `W₀ ∈ R^{d×d}` 冻结；`A ∈ R^{r×d}` 用 Kaiming 初始化；`B ∈ R^{d×r}` **零初始化**；`r=4`，`α=8`，`dropout=0.05`。零初始化保证训练开始时模型输出与 Baseline 逐比特一致，便于单变量比较。

- **伪代码**：

```python
# 1) 注入：只替换末端 4 层的 q_proj / v_proj
for blk in vision_tower.blocks[-4:]:
    blk.attn.q_proj = LoRALinear(blk.attn.q_proj, r=4, alpha=8, dropout=0.05)
    blk.attn.v_proj = LoRALinear(blk.attn.v_proj, r=4, alpha=8, dropout=0.05)
freeze_except(vision_tower, keep=[LoRALinear])      # 其余全部 requires_grad=False

# 2) 前向：视觉特征 + 文本 prompt 相似度打分
def forward(clip_frames):                            # clip_frames: [T, 3, 224, 224]
    f = vision_tower(clip_frames)                    # [T, d]，视觉塔冻结
    f = temporal_pool(f)                             # 时间聚合
    s = cosine(f, text_emb) @ score_head.w           # 与异常/正常 prompt 的相似度
    return smooth(s)                                  # 时间平滑后的帧级分数

# 3) 训练：只有 LoRA + 打分头参与梯度
opt = AdamW([p for p in model.parameters() if p.requires_grad], lr=1e-4)
```

- **工程实现要点**：
  - 代码目录见第 6 节；核心函数为 `models/domain_adapter.py::inject_lora()`、`::freeze_except()`、`models/domain_adapter.py::LoRALinear.forward()`；
  - 断点续训与随机种子固定到 `configs/evivad_vlm.yaml`；
  - 部署时一个场景一个 adapter 文件（约 18 MB），可热插拔。

## 4. 创新点二完整实验方案：EAD 证据锚定解码（Evidence-Anchored Decoding）

### （1）概要

- **一句话定位**：把异常解释从「自然语言描述」改造成「带证据引用、可被反例推翻」的可核验输出。
- **要解决的问题**：现有大模型 VAD 流程的解释只做定性抽查，语言流畅性与事实正确性需要分别评估；无法回答「这段解释有多少内容有视频证据支撑」「删掉关键证据后判定是否还成立」。解释生成端已高度拥挤（本领域语料中「文本解释/描述」主题 54 篇），而解释质量与幻觉评测仅 2 篇，形成「生成快、验证慢」的结构性错配。
- **预期收益**：EAR 提升 ≥ 15 个百分点，CFS 提升 ≥ 12 个百分点，HR 下降 ≥ 8 个百分点，且帧级 AUC 不下降（解释约束不得伤害检测）。

### （2）Baseline

- **基线模型**：在 DAA 打分结果之上接入冻结 LLM 解释生成（免训练，贪心/束搜索，温度 0.2），解释为自由文本，不要求引用证据、不设弃权。
- **训练配置**：
  - 主干 LLM 全程冻结，只训练**证据对齐投影头**（2 层 MLP，约 0.6 M）；
  - 优化器 AdamW；投影头学习率 `5e-4`；weight decay `1e-2`；损失权重 `L_EA = 0.3`；
  - 15 epoch；batch 4（每条样本 = 1 个片段 + 1 条解释）；AMP FP16；
  - 调度：warm-up 1 epoch + cosine decay。

### （3）数据集

- **主数据集**：UCF-Crime 测试集（同上，1610/290 官方划分）。
- **跨域验证数据集**：XD-Violence、UBnormal、MSAD（零微调外测）。
- **本创新点新增标注**：从 UCF-Crime 测试集中抽样 800 个片段，建立「最小充分证据集 + 干扰证据 + 反事实标签」三项机制，其中 20% 由人工复核；每段含 1–3 个证据区间与 1–2 个干扰线索。
- **输入与协议**：视觉输入同创新点一（32 帧、8 fps、224×224）；解释输入为「异常分数曲线 + 已检索证据槽位 + 片段摘要」；解释类指标全部在该 800 段子集上报告，检测类指标在全测试集上报告。

### （4）指标和公式

主/辅助/效率指标同第 3 节（AUC、AP、mAP@0.5、EAR、CFS、HR、TCR、参数/延迟/显存），其中本创新点**核心指标为 EAR、CFS、HR、TCR**：

- `EAR = |E_pred ∩ E_gt| / |E_gt|`（证据归因召回）
- `CFS = 1 − (1/M) · Σ_m 1[ ŷ(x_m^−) = 异常 ]`（反事实可反证分，越高越好）
- `HR = N_unsupported / N_statements`（幻觉率，越低越好）
- `TCR = (1/N) · Σ_i tIoU(τ_i^pred, τ_i^gt)`（时序一致性率）

另保留 `BLEU-4`、`ROUGE-L` 作为「流畅度」对照，用以量化「流畅但不可验证」的差距——预期完整方法在 BLEU 上仅有小幅提升，但在 EAR/CFS 上提升幅度相对更大，这一反差本身就是论文的主要分析依据。

### （5）改进的创新点和思路和代码

- **创新动机**：解释评估以**可核验性**为主要指标，并单独报告语言质量。若把解释的每个论断绑定到一个可被独立检查的证据槽位，解释就从「不可证伪的叙述」变为「可证伪的断言」。
- **与 Baseline 的差异**：Baseline 输出自由文本；EAD 输出结构化 schema，并把「引用是否正确」变成可微的训练信号。
- **关键技术模块**：
  - **证据槽位构造**：对片段内候选区间（由粗分数曲线的局部极大与检索到的正常性记忆共同生成）形成槽位集合 `Z = {z_k = (t_s^k, t_e^k, cue_k)}`；
  - **结构化解码约束**：输出 schema 固定为 `{score, evidence:[{t_start,t_end,cue}], explanation}`，解码时对证据字段做受限生成；
  - **证据对齐损失**（对比式）：

    `L_EA = − log [ exp(sim(h_exp, h_{z*}) / τ_c) / Σ_{k} exp(sim(h_exp, h_{z_k}) / τ_c) ]`，

    其中 `h_exp` 为解释 token 的池化表征，`h_{z_k}` 为槽位 `z_k` 的编码，`z*` 为真值证据槽位，`τ_c = 0.07`；
  - **弃权规则**：当 `max_k cos(h_exp, h_{z_k}) < θ_ev` 时，解释字段替换为「证据不足，拒绝判定」。

- **伪代码**：

```python
# 1) 证据槽位与反事实构造
slots   = build_evidence_slots(score_curve, retrieved_memory)     # [(t_s, t_e, cue), ...]
counter = remove_key_evidence(clip, slots, gt)                    # 反事实样本 x^-

# 2) 约束解码：强制输出证据引用
out = llm.generate(prompt, schema=EVIDENCE_SCHEMA, temperature=0.2)

# 3) 证据对齐损失（只更新投影头，LLM 冻结）
h_exp = proj(pool(out.tokens))
h_slot = proj(encode_slots(slots))
loss  = ce(score_head(out.score), label) + 0.3 * info_nce(h_exp, h_slot, z_star)

# 4) 弃权
if max_sim(h_exp, h_slot) < theta_ev:
    out.explanation = "证据不足，拒绝判定"
```

- **工程实现要点**：核心文件 `models/evidence_decoder.py`、`losses/evidence_alignment.py`、`datasets/counterfactual.py`；schema 校验放在 `metrics/explanation_metrics.py::validate_schema()`；幻觉判定用「实体/事件 ↔ 视频可检测内容」的对齐检查器，并保留人工抽检接口。

|---|---:|---:|---|

| CFS ↑ | 38.7 | 57.2 | +18.5 |

## 5. 创新点三完整实验方案：DAG 退化感知门控与置信度弃权（Degradation-Aware Gating）

### （1）概要

- **一句话定位**：将输入质量设为显式建模变量，让方法在退化条件下自动降级并保持受控输出。
- **要解决的问题**：免训练范式隐含假设「输入足够干净」，而真实摄像头视频存在低光、雨雾、压缩、抖动；已有工作指出低光下免训练推理会产生幻觉语义与不稳定分数。领域内鲁棒性与误报代价相关研究数量有限（对抗鲁棒性 2 篇、误报代价 4 篇，且与大模型零接触），而误报导致的告警疲劳正是真实部署中系统被弃用的主因。
- **预期收益**：退化网格平均 AUC 提升 ≥ 5 个百分点，相对性能保持率 RPR 由 0.81 提升到 ≥ 0.90，置信度校准误差 ECE 下降，干净集性能基本不退化（下降 ≤ 0.3 个百分点）。

### （2）Baseline

- **基线模型**：B0（或 B0 + DAA + EAD）作为对照，无质量门控、无弃权。
- **训练配置**：
  - Q-Net（质量评估探针：3 层卷积 + GAP + 1 层全连接，约 0.2 M 参数）单独训练，标签由退化类型与强度自动生成（干净=1，退化=强度映射分）；
  - 门控与弃权阈值在**验证集**上网格搜索，测试集不参与调参；
  - 优化器 AdamW；Q-Net 学习率 `1e-3`；weight decay `1e-2`；10 epoch；batch 8；AMP FP16。

### （3）数据集

- **主数据集**：UCF-Crime 测试集 + **退化网格**（4 类退化 × 3 强度 = 12 配置）。
- **跨域验证数据集**：XD-Violence 退化子集、UBnormal 退化子集（检验降级机制是否跨数据集成立）。
- **输入与协议**：视觉输入同前；退化注入在**评测阶段**对测试集离线生成并固定随机种子（保证可复现）；干净集与退化集使用同一评测脚本与同一阈值搜索协议。

### （4）指标和公式

**退化鲁棒性指标**

- 相对性能保持率：`RPR = M_deg / M_clean`（退化后主指标 ÷ 干净集主指标）。
- 阈值漂移：`Δτ = |τ*_deg − τ*_clean|`，`τ*` 为验证集上最优阈值。

**校准与弃权指标**

- 置信度校准误差：`ECE = Σ_{m=1}^{M} (|B_m| / n) · |acc(B_m) − conf(B_m)|`，把预测按置信度分桶后取加权偏差。
- 弃权选择性 ASD：弃权样本中「真困难样本（退化强度高或标签边界模糊）」的比例，越高说明弃权越有意义。
- 退化下误报率 `FPR_d`：非异常片段被判为异常的比例（越低越好）。

**主/辅助/效率指标**：AUC、AP、mAP@0.5、EAR、CFS、HR（同前）；效率指标额外包含门控开销（Q-Net 前向时间）。

### （5）改进的创新点和思路和代码

- **创新动机**：与其追求「在所有条件下都更强」，不如让系统**知道自己什么时候不可信**。弃权是可部署性的关键——宁可交给人，也不要给出高置信的错误告警。
- **与 Baseline 的差异**：Baseline 对所有输入使用同一打分路径、同一阈值、不提供弃权；DAG 增加一条「质量→路径权重」的调制通道与一个弃权出口。
- **关键技术模块**：
  - **质量评估**：`q = QNet(frames) ∈ [0,1]`；
  - **门控函数**：`g(q) = σ((τ − q) / T)`，`τ = 0.5`，`T = 0.15`；`g→0` 采用常规路径，`g→1` 采用检索/先验主导路径；
  - **融合打分**：`s = (1 − g)·s_vl + g·(0.7·s_ret + 0.3·s_prior)`，其中 `s_vl` 为视觉-文本对齐分，`s_ret` 为检索证据分，`s_prior` 为定义/规则先验分；
  - **弃权规则**：`|s − τ_s| < δ` 时置弃权位（`τ_s = 0.5`，`δ = 0.08`），输出「低置信，转人工复核」。

- **伪代码**：

```python
def evivad_forward(frames, memory, rules):
    q  = qnet(frames)                                  # 输入质量分
    f  = vision_tower(frames)                          # 冻结塔 + DAA 旁路
    s_vl   = cosine(f, text_emb).mean()
    s_ret  = retrieve_score(f, memory, topk=8)
    s_pri  = rule_score(f, rules)
    g      = torch.sigmoid((TAU - q) / TEMP)           # 质量越低，g 越大
    s      = (1 - g) * s_vl + g * (0.7 * s_ret + 0.3 * s_pri)
    abstain = abs(s - TAU_S) < DELTA                   # 低置信则弃权
    return s, g, abstain
```

- **工程实现要点**：核心文件 `models/quality_gate.py`、`datasets/degradation.py`、`eval/degradation_grid.py`；退化注入需固定种子并缓存，避免每次评测重新生成；门控与弃权阈值必须在验证集在验证集确定后保持固定。

### （6）预计的提升

|---|---:|---:|---|
| 干净集 AUC ↑ | 76.8 | 77.6 | +0.8 |
| 退化网格平均 AUC ↑ | 62.5 | 71.3 | +8.8 |
| 退化下 RPR ↑ | 0.81 | 0.92 | +0.11 |
| 退化下 HR ↓ | 41.2 | 31.5 | −9.7 |

## 6. 三模块组合：完整方法 EviVAD

**流程**：摄像头视频流（32 帧 / 片段）→ 可选退化注入 → 质量评估探针 Q-Net → 冻结 VLM 视觉编码器（+ DAA 低秩旁路）→ 检索增强正常性记忆 → DAG 门控 → 异常打分头 → EAD 证据锚定解码 → 输出「异常分数曲线 / 时间区间 / 证据引用解释 / 置信度与弃权」。

**联合训练目标**：

`L_total = L_score + 0.3 · L_EA + 0.2 · L_gate + 0.1 · L_reg`

其中 `L_score` 为检测打分损失（BCE + 排序），`L_EA` 为证据对齐损失，`L_gate` 为质量预测损失，`L_reg` 为 LoRA 参数正则（抑制过拟合）。
