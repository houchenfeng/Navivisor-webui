# 实验 06：零微调跨域泛化

## 目标与假设

检验只在 UCF-Crime 配置的 EviVAD 能否零微调迁移到 XD-Violence、UBnormal 和 MSAD。假设三个外测集均不出现相对 B0 的负增益，并报告域间差异而非只报平均数。

## 协议

- 不使用外测测试标签训练、调阈值或选择 checkpoint。
- 统一 32 帧、8 fps、224×224；类别通过公开映射表对齐到 normal/anomaly。
- 报告 AUC、AP、RPR、ECE；解释指标仅在具备合法证据标注的子集计算。

## 执行步骤

1. 固化 UCF-Crime 验证阈值和模型配置。
2. 校验三个数据集清单及许可证记录后分别推理。
3. 逐数据集报告 B0 与 EviVAD 聚合结果，并列出域偏移类型。
4. 输出 `cross-domain.csv`；缺少可追溯数据时明确记录数据缺口。

## 验收与风险

至少两个外测集 AUC 增益 ≥2 点，且无数据集下降超过 1 点。风险包括标签定义不一致、合成域偏差和测试集泄漏。

## 结果分析

现有数据呈现三个外测集均为正增益，相关泛化结论需要结合独立实验进一步确认。
