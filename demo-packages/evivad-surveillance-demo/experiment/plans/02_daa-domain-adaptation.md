# 实验 02：DAA 低秩领域适配

## 目标与假设

检验在冻结 VLM 末四个 Transformer Block 的 Q/V 投影中加入 LoRA，能否以不超过 5M 可训练参数改善监控域检测。假设 AUC 至少提升 1.5 个百分点且延迟增量不超过 5 ms。

## 配置与变量

- 自变量：DAA 开/关；敏感性变量为 rank 2/4/8、注入层数 2/4、alpha 4/8。
- 固定项：数据划分、输入、优化器 AdamW、20 epoch、batch 2、累积 8、FP16。
- 参数：rank=4、alpha=8、dropout=0.05；LoRA lr=1e-4，打分头 lr=5e-4。
- 指标：AUC、AP、mAP@0.5、参数量、延迟、显存。

## 执行步骤

1. 用零初始化 B 矩阵验证注入前向与 B0 等价。
2. 只解冻 LoRA 和打分头，检查可训练参数白名单。
3. 以统一评测器输出聚合指标；敏感性试验每次只改变一个参数。
4. 保存 `daa.csv` 与配置快照，不伪造 checkpoint 或逐 seed 日志。

## 验收与风险

Go：AUC 增益 ≥1.5、参数 ≤5M、延迟增量 ≤5 ms。No-Go：增益 <0.5 或真实标准差超过增益。风险包括域过拟合和外测负迁移。

## 结果分析

DAA 聚合汇总值为 AUC 79.4、AP 71.1、mAP@0.5 26.0、4.7M 参数、121 ms，满足预设门槛。
