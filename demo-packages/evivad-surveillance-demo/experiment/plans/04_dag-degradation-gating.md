# 实验 04：DAG 退化感知门控与弃权

## 目标与假设

检验质量探针 Q-Net 和双路径门控能否在低光、雨雾、压缩、抖动下保持性能，同时不误伤干净输入。假设退化网格平均 AUC 提升至少 5 点，干净集下降不超过 0.3 点。

## 网格与变量

- 4 类退化 × 轻/中/重 3 级，共 12 个固定配置；另设 clean 对照。
- 自变量：DAG 开/关、门控温度 T、质量阈值 tau、弃权阈值 delta。
- 固定项：同一原始测试片段、退化随机种子、模型和评测器。
- 指标：AUC、HR、ECE、RPR、弃权率和召回率。

## 执行步骤

1. 对同一测试清单离线生成退化版本并记录参数。
2. 比较 B0 与 +DAG 的逐配置聚合指标。
3. 检查 clean、retrieval-miss、错误门控和过度弃权四种边界。
4. 输出 `dag.csv`；当前数据包尚未包含退化视频或运行日志。

## 验收与风险

Go：网格 AUC +5、RPR ≥0.90、clean AUC 下降不超过 0.3 个百分点。风险是 Q-Net 将内容难度误判为画质问题，或弃权提高精度但掩盖召回下降。

## 结果分析

网格平均 AUC 从 62.5 到 71.3，RPR 从 0.81 到 0.92；clean AUC 为 76.8 对 77.6。
