\begin{abstract}
We study inference-cost control for fixed-camera video anomaly detection (VAD).
A lightweight scorer proposes anomaly scores and uncertainty; uncertain clips trigger
scene-normal memory retrieval and a vision--language model (VLM) review with structured
evidence; scores are fused for the final event. On the synthetic teaching set
\texttt{camera-demo}, the full system reaches 87.1\% AUROC at 12\% VLM call rate versus
81.2\% AUROC for the lightweight baseline and 100\% calls for VLM-all.
\textbf{All metrics are simulated teaching numbers, not real benchmark claims.}
\end{abstract}

\section{Introduction}
Fixed cameras generate continuous video. Calling a VLM on every clip is expensive;
lightweight detectors alone struggle on ambiguous events. We ask whether scene memory
can improve hard-clip recognition and explanation under a fixed review budget.
Contributions in this teaching demo: (I1) uncertainty trigger, (I2) scene-normal memory,
(I3) evidence-bearing VLM review with calibrated fusion.

\section{Method}
Pipeline: sample $\rightarrow$ fast score $(s,u)$ $\rightarrow$ trigger
$\rightarrow$ memory $\rightarrow$ VLM $\rightarrow$ fuse $\rightarrow$ event.
Uncertainty $u=1-|2s-1|$. Trigger when $s\ge 0.65$ or $u\ge 0.2$.
Memory uses top-$K{=}5$ train-normal entries only.
Fusion weights default to $0.4/0.2/0.4$.
