# Related Work

本 Demo 使用三条合成文献作为教学引用（非真实出版物）：

- **Fast screening** (`demo_fast_screening`, DEMO-001)：轻量评分筛选可疑摄像头片段。
- **Memory retrieval** (`demo_memory_retrieval`, DEMO-002)：正常场景记忆支持检索与比对。
- **Language-guided verification** (`demo_vlm_verify`, DEMO-003)：VLM 解释不确定事件片段。

真实文献检索与核验不在本包范围内；`synthetic=true`，`verified=false`。阅读器用 PDF 均为标明 SYNTHETIC SAMPLE 的合成样例。
