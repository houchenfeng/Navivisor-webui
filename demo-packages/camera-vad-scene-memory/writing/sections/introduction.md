# Introduction

固定摄像头场景中，逐段调用视觉语言大模型（VLM）成本过高，而纯轻量检测又难以解释疑难片段。本文教学 Demo 研究：在固定预算下，场景正常记忆与不确定性触发能否改善异常识别与可解释性。

科学问题（与确认选题一致）：场景记忆能否在固定预算下改善疑难片段识别和解释？

贡献（模拟设定）：

1. **I1 不确定性触发**：仅复核高分或不确定片段。
2. **I2 场景正常记忆**：从训练正常片段检索对照。
3. **I3 证据化 VLM 复核**：结构化 JSON 证据并与快路径融合。

披露：全部实验为 synthetic/simulated，仅用于 Navivisor 工作流演示。
